# AI-CodeLens

**AI Destekli Kod İnceleme Asistanı**

## Proje Hakkında
AI-CodeLens, yazılım geliştiricilerin kaynak kodlarını incelemelerine, olası hataları tespit etmelerine ve kod kalitesini artırmalarına yardımcı olmayı amaçlayan yapay zekâ destekli bir asistandır.

## Projenin Amacı
Projenin amacı, kod inceleme sürecini kolaylaştırmak, kodlama standartlarına uygunluğu değerlendirmek ve daha okunabilir, güvenli ve sürdürülebilir yazılımlar geliştirilmesine katkı sağlamaktır.

## Proje Dokümantasyonu
Proje kapsamında hazırlanan belgeler `docs` klasöründe bulunmaktadır:

- Proje Tanımı Dokümanı
- Gereksinimler Dokümanı
- Tasarım Dokümanı
- Kodlama Standartları Dokümanı
- Test Sonuçları Dokümanı

## Kullanılan Araçlar
- Git
- GitHub
- Visual Studio Code

Proje bireysel olarak yürütülmektedir. Geliştirme sürecinde Git ve GitHub kullanılarak sürüm kontrolü ve proje takibi yapılmaktadır.
